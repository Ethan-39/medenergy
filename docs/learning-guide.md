# MedEnergy 入门练习指南

这是面向初学者的动手路线。先运行看板，再一次只改一个参数；暂时不用先学深度学习。

## 1. 打开演示

双击项目根目录的 `dashboard.html`，或用 Edge/Chrome 打开。看板使用仓库自带的仿真结果，不需安装依赖或联网。

重点看三块：负荷预测曲线、固定与优化排程的购电曲线、模拟任务的时间窗口和约束状态。

## 2. 建立对照

在看板中将“允许任务前后移动”设为 0 小时，观察固定与优化方案重合。再设为 4 小时，观察费用、购电碳排和任务开始时间变化。相同参数下，候选方案可能相同，结果不一定每次都会改善。

## 3. 修改配置并重新运行

安装 Python 3.10+ 后，双击 `run.cmd`，或在项目目录运行：

```bash
python medenergy.py
```

打开 `config.json`，把 `pv_capacity_kw` 从 300 改成 150，再运行。观察光伏自用和结果变化。然后将 `max_shift_hours` 从 4 改为 0，检查排程是否回到固定方案。一次只改一个参数，并记下结果。

## 4. 认识数据

`data/hospital_energy.csv` 有 30 天、每 15 分钟一行的仿真数据。先看这些字段：

| 字段 | 含义 |
| --- | --- |
| `timestamp` | 时间戳 |
| `forecast_temperature_c` | 模拟的提前天气预报 |
| `planned_occupancy_ratio` | 模拟计划占用率 |
| `actual_background_kw` | 模拟实际背景功率 |
| `baseline_task_kw` | 固定方案中的可移动任务功率 |
| `pv_forecast_kw` / `pv_actual_kw` | 模拟光伏预测/实际功率 |
| `tariff_yuan_per_kwh` | 教学用模拟电价 |
| `carbon_kg_per_kwh` | 教学用模拟碳因子 |

kW 是功率，kWh 是能量。15 分钟的用电量等于功率乘以 0.25 小时。例如 32 kW 运行 45 分钟，对应 24 kWh。

## 5. 按顺序读核心代码

打开 `medenergy.py`，按这个顺序定位：

1. `generate_data()`：生成用于教学的模拟输入。
2. `features()`：选择预测时可用的输入特征。
3. `fit_linear_regression()` 和 `predict()`：训练并使用线性回归。
4. `errors()`：计算 MAE 和 RMSE。
5. `optimize_day()`：枚举允许窗口内的开始时刻。
6. `evaluate_day()` 和 `verify_plan()`：用模拟实际值回放并检查能量、时长和截止时间约束。

## 6. 术语速查

- **训练集**：用于拟合模型的数据。
- **测试集**：训练阶段不使用、最后用于检查模型的数据。
- **时间顺序切分**：先前日期训练、之后日期测试，避免未来信息泄漏。
- **基线**：简单但明确的对照方法；这里是昨天同一时刻的负荷。
- **MAE**：平均绝对误差，越低表示预测与实际的平均距离越小，单位与负荷相同。
- **RMSE**：均方根误差，对较大的误差惩罚更强。
- **排放因子**：每单位活动对应的温室气体排放量；真实分析必须标明来源、地区、年份和单位。
- **情景回放**：把候选方案放在同一组模拟条件下估算结果，不等于现场验证。

## 7. 重要边界

所有负荷、任务、光伏、电价和碳因子都是仿真输入。本项目只移动两个互不重叠窗口内的模拟批次；固定医疗负荷、影像预约、通风等不移动。它不控制真实设备，也不能证明真实节能或减排。
